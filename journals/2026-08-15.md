# String in java #dsa 
- String declaration `String str = "this is a string"`
- Comparision of strings: `str1.compareTo(str2) == 0`
	- `compareTo()` function checks for 
		- 1. S 1 > S 2 (returns +ve value)
		- 2. S 1 == S 2 (returns 0)
		- 3. S 1 < S 2 (returns -ve value)
	- Checks for int values of each character
	- Why use compareTo() when == already exists
		- == fails testcases compared to compareTo()
- Substring of string: `str.substring(startIdx, endIdx)`
	- If endIdx is not specified then substring ends with endIdx of string
## String in java are immutable
- Everytime a string is edited in java the existing string is destroyed and a new string is created everytime and referenced by the variable
- This increases the operation time for various actions of the string
# StringBuilder #dsa 
- StringBuilder is a object and a mutable version of String
- Declaration: `StringBuilder sb = new StringBuilder("Tony");`
- Char at Idx: `sb.charAt(idx)`
- Set char at idx: `sb.setCharAt(idx, char)`
- Insert: `sb.insert(idx, char)`
- Delete: `sb.delete(startIdx, endIdx)` (endIdx excluded)
- Append: `sb.append("str")`
- Length: `sb.length()`
# Bit Manipulation #dsa
- Procedure
	- Create a bit mask
	- Perform bit operations (and &, or |)
## GetBit
- Bitmask: 1 << i
- Operation: and
- If operations returns o, then the bit is 0, else the bit is 1
## SetBit
- Bitmask: 1 << i
- Operation: or
- Setbit sets the bit of position to 1
## ClearBit
- Bitmask: 1 << i
- Operation: and with not bitmask
- Clears the bit to 0 at pos
## UpdateBit
- Bitmask: 1 << i
- Operation: xor (or) setBit and clearBit wrt getBit
- Toggles the bit at position
