# Organizing notes in obsidian
- Obsidian can be organized with tags, links, folders, databases, metadata
- Tags: Simple and Flexible
	- Tags are better than folder, since a note can only be put in one folder but tags allow a note to have multiple categories
	- Limit tags
- Link stuff only when a note is related and requires attention
	- Ex: referencing minimax algorithm in note about alpha beta pruning
**When using obsidian for note taking use it the obsidian way**
**Always limit your tags, and connect information that needs connection with links**
***Never make any unnecessary connections***
# German Characters not in English
- Ää - A-umlaut
- Üü - U-umlaut
- ẞß - Eszett (sharp S)
- Öö - O-umlaut
- To type these characters use `compose key (ralt) + " + the letter (a, o, u, s)`

# How to use SSH Keys in github
- copy the ssh key and add it in github
```bash
$ cat ~/.ssh/id_ed25519.pub
# Then select and copy the contents of the id_ed25519.pub file
# displayed in the terminal to your clipboard
```
- start ssh-agent in background
	- `eval "$(ssh-agent -s)"`
- start ssh-agent on user profile with systemctl
	- `systemctl --user start ssh-agent`
- add your key to the ssh-agent
	- `ssh-add ~/.ssh/id_ed25519`
- Now you can push into remote git repo
