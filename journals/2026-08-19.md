# Basic Sorting Techniques
- Sorting is process of arranging items in an order (generally in ascending or descending)
- Most basic sorting techniques without using recursion are
	- Bubble sort 
	- Selection sort
	- Insertion sort
# Bubble sort
- Algorithm
	- Run a loop for n-1 number of items in the array (the last element will be sorted automatically)
	- Run a loop for each iteration for n - i - 1 times
	- Compare the pairs and move the largest or smallest element to the end
- Time complexity = O(n^2)
- Not the best sorting technique but the easiest sorting code
```java
public static int[] bubbleSort(int[] arr){
    for(int i=0; i<arr.length-1; i++){
        for(int j=0; j<arr.length - i - 1; j++){
            if(arr[j] > arr[j+1]){
                int temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
            }
        }
    }
    return arr;
}
```
# Selection sort
- Algorithm
	- Run loop for n-1 items in the array (the last element will be sorted automatically)
	- Run another loop to find the smallest element from index i+1 to the end of the array
	- Swap the smallest element to i th index
- Time complexity = O(n^2)
- One swap for iteration
- Better than bubble sort in terms of time complexity
```java
public static int[] selectionSort(int[] arr){
    for(int i=0; i<arr.length-1 ; i++){
        int smallIdx = i;
        for (int j = i+1; j < arr.length; j++) {
            if(arr[smallIdx] > arr[j]){
                smallIdx = j;
            }
        }
        int temp = arr[i];
        arr[i] = arr[smallIdx];
        arr[smallIdx] = temp;
    }
    return arr;
}
```
# Insertion sort
- The array is divided into two parts i.e, sorted and unsorted using pointers and elements in unsorted part are put into sorted part
- Algorithm
	- Run loop for n items in the array
	- Create a pointer j which tracks the last position of sorted part of array and curr which tracks the value of current element
	- if curr value is less than j
		- Make space for the smaller element by pushing the jth element to the right
		- Check the before element
	- If the curr value is not less than j
		- Then place the element at j+1 position
- Time complexity = O(n^2)
```java
public static int[] insertionSort(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        int curr = arr[i];
        int j = i-1;
        while(j >= 0 && curr < arr[j]){
            arr[j+1] = arr[j];
            j--;
        }
        arr[j+1] = curr;
    }
    return arr;
}
```
